# Kirke v0.2.0.0 — Trading state and historical crypto data

**Kirke** is an unofficial, read-only Haskell command-line client for Alpaca's paper Trading API and Crypto Market Data API, developed alongside [Medea](https://github.com/black-belt-badger/medea) in Rust. This is a public **prerelease**; the CLI and output contracts may evolve.

## What's new since v0.1.0.0

- **Paper account state:** `kirke positions` lists open crypto/equity positions; `kirke assets` discovers tradable assets and filters by class/status.
- **Order inspection:** `kirke orders` filters paper orders by status, limit, and symbol; `kirke order get ORDER_ID` retrieves a single order by validated UUID, with optional nested legs. All operations are read-only.
- **Historical crypto bars:** `kirke crypto bars` fetches OHLCV bars with symbol list, location, timeframe, dates, sort, page limit, and explicit bounded pagination.
- **Historical crypto trades:** `kirke crypto trades` fetches individual executions with exact integer IDs, precise decimal prices and sizes, original timestamp strings (including nanoseconds), and optional taker side. Trades are processed one page at a time.
- **Exports:** human-readable summaries, complete original provider JSON in atomic private files, and symbolized JSONL for bars/trades. File exports preserve unknown provider fields in JSON envelopes, keep continuation tokens, and roll back after later-page failures.
- **Docs and identity:** project-specific README branding, lightweight image assets, security and contribution documentation, plus live integration scripts for maintainers.

## Example commands

```sh
mkdir -p output
chmod 700 output
kirke account
kirke positions --out output/positions.json
kirke assets --status active
kirke orders --status all --limit 10
kirke crypto bars --symbols BTC/USD,ETH/USD --timeframe 1Hour --max-pages 2 --out output/bars.json
kirke crypto trades --symbols BTC/USD,ETH/USD --max-pages 2 --format jsonl --out output/trades.jsonl
```

## Build and install (source distribution)

Requires **GHC 9.10.3**, **Stack 3.11.1**, and a compatible Unix-like environment.

```sh
git clone https://github.com/black-belt-badger/kirke.git
cd kirke
git checkout v0.2.0.0
stack build
stack test
stack install
kirke --help
```

See the [README](https://github.com/black-belt-badger/kirke/blob/v0.2.0.0/README.md) for authentication and command options. Use `APCA_API_KEY_ID` and `APCA_API_SECRET_KEY` from your environment, **never CLI arguments or committed files**.

## Safety, limitations, and distribution

- Uses Alpaca's **paper trading** endpoint for account/order reads and **market data** endpoint for historical bars/trades. No live trading, order placement/cancellation, historical crypto quotes, or streaming data in this release.
- API requests are bounded by validated page counts. JSONL to stdout can be partial if a later page fails; use `--out` for atomic private exports. JSONL does not retain continuation tokens.
- No Hackage publication or prebuilt binaries: GitHub provides versioned source archives. Build locally with the pinned toolchain.
- This is an **unofficial** open-source project, not affiliated with or endorsed by Alpaca Markets.
